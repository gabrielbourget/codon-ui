## Ownership And Accepted Contracts

`packages/react` owns canonical React source, theme CSS and registry definitions; `packages/react-native` owns shared TypeScript/TSX native components and typed native theme. `apps/native-showcase` owns its generic Expo consumer and app-only Intl bootstrap. `apps/web` does not own canonical registry source or artifact generation. `packages/CLI` owns current source-distribution CLI behavior; `apps/docs` owns durable documentation. Sibling repositories remain separate; this work does not edit Wavemap or Waveguide.

Controlled values remain authoritative, including false, zero, empty string/array and contract-defined null. Undefined alone selects the documented uncontrolled/default path. Preserve event-count protection, existing callback/veto semantics, native refs and style precedence. Do not add effect-driven mirrors, uncontrolled fallback or event suppression to make an automated text test pass. Component [types](../../packages/react-native/src/index.ts), focused suites and the curated [native package reference](../../apps/docs/src/content/docs/packages/react-native.md) own the implemented API; past proposal text does not authorize additional APIs.

Verify public behavior, callbacks, refs, labels, dimensions/geometry/size, focus/validation, named slots and override precedence, then add native keyboard/window/accessibility proof. Test counts, mocks and a passing repeated native typing case cannot certify coverage parity.
