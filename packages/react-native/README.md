# @codon-ui/react-native

Private native-owned Codon foundation for the Expo SDK 57 / React Native 0.86.3 / React 19.2.3 laboratory. The package exports native Text, PlaceholderText, Button, Switch, Checkbox, CheckboxGroup, Input, TextArea, Radio, RadioGroup, NumberInput, Select, ComboBox, ListBoxItem, Modal, AlertDialog, the theme/overlay providers, hook and public types. Further component families follow the compatibility roadmap; closer owner visual review accompanies application feature integration.

```sh
pnpm -F @codon-ui/react-native build
pnpm -F @codon-ui/react-native typecheck:contracts
pnpm -F @codon-ui/react-native test --runInBand
```

Metro's react-native export resolves canonical TypeScript source; types and compiled imports use dist. Build before checking consumer types. React and React Native are exact lab peers; Expo is owned by the consumer. The native package has no DOM, React Aria, Expo or CSS runtime imports.

The approved Select pass adds react-native-safe-area-context 5.7.0 as an exact peer/development dependency, matching the showcase. Consumers install that peer and complete normal native linking/build steps. Select's modal owns its safe-area provider; Expo remains consumer-owned.

NativeThemeProvider selects explicit light/dark defaults and applies typed partial overrides. Nested providers are independent; omitted mode selects light. useNativeTheme outside a provider returns light defaults. Overrides apply to named roles, not an automatic palette regeneration. System fonts and native line metrics are the defaults, with user text scaling retained by consuming Text views. CSS-variable color strings are not native color inputs even though RN's string color type accepts them.

Tests own public provider behavior. They use the native Jest preset and RNTL 14's async API. Read installed RNTL docs before changing tests; showcase Expo seams have a separate test owner. Passing mocked tests/Metro bundles is not native rendering, accessibility, touch geometry or device acceptance.

`Text` is the native typography component. It uses the provider's 31 variants and six weights, native line metrics and uncapped system scaling. Heading/link intent and explicit native roles are separate from font variants. Ordinary text defaults selectable; label and Button-owned content default unselectable, with an explicit `selectable` override. Native labels/IDs win over `aria-label`/`data-testid` aliases. RN Text refs and native events are retained; DOM class/form/click props are unsupported.

Text resolves provider/inherited foreground, own color, custom native styles and final native styles in that order. Nested Text inherits the resolved foreground unless it supplies its own color/styles. Consumed color fields reject unresolved CSS variables and `currentColor` at runtime while supporting RN platform colors. Unit/provider tests resolve the public source barrel; the external archive separately proves compiled package consumption.

The [canonical execution ledger](../../planning/component-library/roadmap.md) owns SDK/source revisions, review receipts, evidence limits and subsequent gates. Native registry/CLI lifecycle, package publication and shared runtime token extraction remain later decisions.

`Button` uses a View-backed Pressable ref and native event payloads. It wraps string/number children with Text; nested Text inherits the final root foreground. Render children receive that foreground for icons. Its state exposes pressed, hovered, focused, disabled and pending flags; focus-visible, HTML form, click and press-up APIs are unsupported. Pending announces busy and suppresses activation while retaining focus eligibility. Disabled also disables focus. Blocking an active gesture clears its presentation and balances already-started end/change callbacks.

Button resolves computed base/state styles, custom styles and final styles in order. An explicit hover color wins in the computed hover layer; pressed state wins over hover. Custom colors keep their base pressed appearance. Transparent hover computes a clear background, while explicit final backgrounds still win. This approved native precedence differs from the current web cascade. Default unconstrained targets have a 44-point iOS / 48-dp Android minimum and can grow with text. Explicit dimensions remain authored. Hit testing follows native parent geometry and overflow policy; an unclipped parent can allow activation outside its bounds. Hosts requiring a strict parent boundary must explicitly clip overflow. Measured hit slop does not establish adjacent-target acceptance.

Switch and Checkbox use View-backed Pressable refs. isSelected/onChange(boolean) control selection; defaultSelected initializes uncontrolled selection once. Disabled and read-only suppress mutation and activation, while only disabled sets disabled presentation/state. Supply a localized read-only hint when needed. Switch labels use leftContent/rightContent; its 15 × 30 default track and Checkbox's 20 × 20 default shape are separate from the automatic target minima. Numeric visual dimension props, geometry/order, focus and native color/custom style contracts are preserved. Switch has authored icon slots and track/thumb styles; OS switch drag/animation behavior is outside this counterpart. Checkbox supports mixed state, which stays caller-owned and announces checked mixed even when showIcon is false. Primitive/Fragment labels wrap and remain unselectable; authored elements are preserved.

CheckboxGroup coordinates string-valued Checkbox members through private context, including members inside ordinary native wrappers. Controlled value/onChange or defaultValue owns selection; member selection props do not override the group. Group disabled/read-only flags block members, nested groups isolate state and values are updated without mutating caller arrays. Members remain separate accessibility targets. DOM form validation/submission and table slot context remain host/later-family work.

Input forwards a core TextInput ref and native value/defaultValue, onChangeText/onChange/submit/focus/selection events. It is single-line, retains native text scaling and keyboard options, and uses isDisabled/isReadOnly instead of editable/readOnly aliases. Small/medium/large map to b11/b10/b9. Error/warning/success props set border presentation in that priority; host form logic owns messages and validation. Input style callbacks receive focus/disabled/read-only/invalid flags and a post-custom defaultStyle, without hover/focus-visible claims. Twelve added theme color roles copy existing canonical control/validation colors; existing defaults and action ramps remain unchanged. Hosts should use the native submit event's final text when committing a form value. The showcase owns safe-area, scroll and keyboard reachability.

ListBoxItem is a controlled radio row with required typed id and nonempty textValue. The text metadata owns its accessible name; visual children are decorative and must not contain nested interactive controls. Selection is represented by isSelected; disabled/read-only suppress activation, and only disabled changes opacity/accessibility disabled state. Primitive/Fragment content uses owned Text, with native font scaling, selected/hover/pressed theme roles, target minima and post-custom style callback precedence.

Select receives an immutable items array plus getKey/getTextValue and optional renderItem content. Numeric and string keys remain distinct; duplicate/non-finite keys and empty text metadata fail descriptively in production too. value/onChange and isOpen/onOpenChange are independently controlled, with defaultValue/defaultOpen for uncontrolled initialization. null explicitly clears selection. Removed values keep their key and show the placeholder until reinserted; there is no automatic onChange. Selecting an enabled row requests its key before closure; choosing the existing value or cancelling closes without a redundant selection callback. Read-only opens for inspection but suppresses changes. Disabled prevents opening and requests closure once if an owner holds controlled open true. Require a localized accessibilityLabel/aria-label and closeLabel; hosts provide explanatory read-only and validation hints.

The native presentation is an opaque full-screen core Modal, containing a heading, Close button and variable-height virtualized FlatList. Its own safe-area provider handles the modal window. Initial selected-row positioning waits for measurements and uses a collection-sized retry budget capped at 32 measured attempts; native Back/accessibility escape share the close path. Focus work is cancelled on unmount/reopen; iOS dismissal and bounded Android native frames return accessibility focus to the surviving trigger. These implementation paths require installed/physical verification and do not certify VoiceOver/TalkBack from mocks. placement, shouldFocusWrap, DOM forms/links/classes, obsolete selected-key aliases, multi-select, search and web keyboard/typeahead behavior are excluded from this counterpart.

Select forwards the trigger View ref. Root customStyles/final style, customSelectedItemStyles, customSelectedItemTextStyles and customOptionsListStyles have separate ownership. Root callback state contains open/disabled/read-only/invalid and a post-custom defaultStyle; explicit root dimensions remain caller constraints. renderSelectedValue receives selectedItem, selectedText and isPlaceholder without React Stately state. ComponentIcon undefined draws the native chevron; explicit null hides it. Geometry, b11/b10/b9 sizes, existing focus/validation/control roles and uncapped native text scaling are preserved without palette additions.

TextArea retains Input's native editing, event, ref, validation and styling contracts while owning multiline=true and requiring a nonempty accessibilityLabel/aria-label. Its default 96-unit height is caller-overridable; content scrolls natively without automatic growth. numberOfLines is a native hint, Android text starts at the top, and Return defaults to newline. Explicit submitBehavior remains available; blurOnSubmit, clearButtonMode, secureTextEntry and CSS resize are excluded. onContentSizeChange forwards the native event without resizing. Disabled and read-only block mutation; only disabled changes opacity and focus eligibility. Hosts own keyboard reachability and use final native submit text when committing.

Radio requires a nearest RadioGroup and a unique stable string value, including an empty string. RadioGroup owns value/string-or-null, initial defaultValue and onChange(string); null explicitly clears a controlled value, and controlled members wait for parent echo. Reselection and removal are quiet; reinsertion restores a retained value. Members inside ordinary wrappers work through private context, and nested groups isolate state and guards. Group disabled/read-only owns members; member isDisabled may add a restriction. Only disabled changes opacity, once per member. Require nonempty accessible names on group and members; the nonaccessible radiogroup wrapper preserves individual radio targets. Hosts own localized read-only/validation explanations and physical announcement review.

Radio uses a fixed 20-unit native mark, existing geometry/order/color/focus roles and stable selected fill during hover/press. Width/height and customStyles/final style constrain the target; customShapeStyles owns the mark. Explicit color controls the mark without recoloring the label. Primitive/array/Fragment labels use native Text with uncapped scaling; authored children remain decorative. Automatic 44-point/48-dp target minima and clipped-parent exceptions follow the existing controls. RadioGroup defaults to vertical flow with two spacing units; horizontal flow wraps. Native refs and callbacks are retained without DOM form or web keyboard coordination.

NumberInput composes the existing native Input/Button into three independently named targets. Supply accessibilityLabel (or aria-label), incrementLabel and decrementLabel. The forwarded ref is the core TextInput. value/defaultValue are number or null; undefined value selects uncontrolled initialization. onChange publishes accepted commits/steps, while onChangeText observes complete raw native edits. Submit/end-edit use final native text, deduplicate the same edit and restore invalid drafts. Blur alone does not commit. Controlled requests return to the authoritative prop until the parent echoes; same-valued rerenders preserve drafts, while changed value/configuration or guard takeover cancels them. Use a keyed remount for a same-value reset; switching control mode is unsupported.

The exact direct runtime utility @internationalized/number 3.6.6 supplies public decimal parsing/formatting. locale defaults explicitly to en-US; hosts choose their locale and numbering-system extension. formatOptions accepts only decimal style, grouping and minimum/maximum fraction digits from zero through six. Numeric props must be finite, exactly representable at the configured precision and safe in scaled integer units. Invalid props throw TypeError; unsafe transactions are rejected. Valid drafts round half away from zero, clamp bounds and snap only when step is explicit, anchored at minValue or zero, with ties away from the anchor and an off-grid maximum capped below. Omitted step preserves typed decimals while buttons use the one-unit grid. Supplied values are not eagerly clamped. Empty commits publish null; empty/unparseable step actions seed min/max or zero once. The pinned parser tolerates repeated grouping and detects localized digits; it does not guess cross-script decimal separators. Exponent, hex and plus-sign drafts are excluded.

NumberInput owns the editor's value/events/identity/actions; inputProps is a narrow native keyboard/color/selection/observer allowlist. Root customStyles/final style, inner customGroupStyles, customInputStyles and common customButtonStyles have separate ownership. The root is nonaccessible and does not dim all children; disabled opacity applies once per child branch. Read-only blocks mutation without disabling the step Buttons' focus/presentation. Numeric bounds disable only unavailable directions. The editor retains native editing semantics with available custom incrementValue/decrementValue actions using the same guarded step path as touch. It does not promise adjustable swipe or web spinbutton announcements. Default wrapping layout preserves separate 44-point iOS / 48-dp Android targets; authored constraints retain the normal clipping/target exceptions. Default glyphs use decorative Views; explicit null hides them. Native keyboard layouts are hints, not separator/Return guarantees. Repeat, wheel/hardware-arrow handlers, web form/validation state and arbitrary numeric formats remain outside this contract.

NumberInput requires Intl.NumberFormat.formatToParts, supported locale/numbering data and the configured decimal precision. A missing operation throws a contextual TypeError. Consumers must prepare required Intl support before importing the native barrel so formatter feature probes/caches initialize against that runtime. The library does not install a global polyfill implicitly; a complete existing formatter needs no replacement. The [showcase bootstrap](../../apps/native-showcase/src/runtime/number-format.ts) is an explicit app-owned example using the four exact dependencies in [the approved Intl plan](../../planning/component-library/roadmap.md#native-runtime-and-distribution). Independent consumers declare and initialize their own dependencies/data. Only the application runtime is prepared; Expo, React and native peers remain consumer-owned.

Locale tags are canonicalized before parser construction, including case-insensitive numbering-system extensions. Changed option values/keys cancel the edit even when the host reuses an option object; equivalent configurations preserve the raw draft. This retains the existing value/configuration transaction contract without exposing the private numeric model or a shared locale provider.

`NativeOverlayProvider` is a children-only application scope required by Modal/AlertDialog. Use one scope at the application root; nested overlay providers are rejected. It owns one active nested root-to-leaf window chain through private context, retaining declarative React locations and caller/theme context. Concurrent sibling branches or unrelated open roots produce a contextual error. For a root replacement, request the old root closed; native retirement completes before the replacement is admitted. A child waits for parent onShow, and only the active leaf processes dismissal/actions. An already admitted presentation closed before onShow drains readiness while inactive, then dismisses; it cannot admit a child or focus request during that drain. iOS completion uses onDismiss; Android uses a committed hidden-frame barrier. No portal, process-global registry, BackHandler, public registration or dismissAll API is introduced.

`Modal` supports isOpen/onOpenChange or initial defaultOpen and rejects ownership-mode switches. Require accessibilityLabel or aria-label; native names/IDs take precedence over aliases. isDismissable governs only the backdrop, while isKeyboardDismissDisabled governs native system close/accessibility escape. Explicit actions remain available with both guards enabled, and a controlled owner can decline closure repeatedly. Custom children replace the Modal Title / Placeholder text / Close Modal starter composition. Primitive/Fragment phrases receive native Text without cloning authored elements; a complex starter closeButtonText requires an explicit closeLabel. The panel forwards a View ref and uses finite nonnegative static numeric, percentage or auto dimensions, rounded/orthogonal geometry, five action orders and the existing raised recipe. Computed panel styles precede customStyles and final style; customOverlayStyles and customDialogStyles have separate owners. Root color reaches owned content through context.

Modal defaults to a bounded internal scroller, a dim unblurred backdrop and min(400, available padded safe width). isScrollable=false lets a caller own a bounded FlatList/scroller; the library does not discover child types. overlayBlur may be omitted or false; true fails public types and runtime validation. DOM refs/classes/forms, ID association props, portal containers, dialogRole and web animation/trigger/slot props are excluded. Each native window owns its safe-area provider and keyboard handling (iOS padding, Android height), with measured focused-field reveal. Explicit clipping/dimensions remain caller constraints. Native targets, complete content, keyboard and orientation still require installed/physical review.

Covered parent content remains mounted, preserving parent-local state and native control instances. Complete closure unmounts ordinary content, so values that must survive closure belong outside it. Ancestor closure gates descendants and retires windows deepest first without invoking business callbacks. Controlled descendant open values stay caller-owned and may resume with a later ancestor; update those values explicitly when that is unwanted. Optional initialFocusRef/restoreFocusRef identify accessible native targets in the expected active owner. Requests follow native readiness/retirement and cancel on close, replacement or unmount; removed refs remain quiet. Restoration requests accessibility focus rather than calling TextInput.focus to reopen a keyboard. Native automatic restoration and physical spoken output remain separate platform behavior.

Select keeps its standalone API/presentation without an overlay provider. Inside the scope it joins the private chain as a leaf, preserving its opaque full-screen list and known trigger restoration. Row content remains decorative. The provider does not add search, anchored placement, multi-select, HTML forms or web keyboard navigation.

`AlertDialog` uses the same single native window/frame and requires an explicit name plus string titleText/bodyText. Its default info type and warning/error/danger/delete/success types, six constants and AVAILABLE_ALERT_DIALOG_TYPES are exported with props/ref/type/label aliases. AlertIcon undefined/null select the corresponding default native mark; supplied nodes remain decorative. Core Views/Text replace the canonical SVG marks, with fixed decorative icon sizes and uncapped content text. The ribbon, icon circle, heading/body/custom content and nonshrinking wrapping action row share bounded dialog scrolling so actions remain reachable in short keyboard/large-text viewports; there is no fixed-footer promise.

AlertDialog labels resolve the four canonical keys cancelActionButton, cancelActionButtonAriaLabel, confirmActionButton and confirmActionButtonAriaLabel, defaulting to Cancel / Cancel Action / Confirm / Confirm Action. Legacy cancelActionBtnText/confirmActionBtnText replace visible text independently from accessible names. Validate names for rendered actions; showCancelAction=false removes cancellation. An active cancel/confirm callback runs once before requesting false; a synchronous throw prevents closure and a returned promise is not awaited. Backdrop/system/external closure invokes neither business callback. Async pending/errors, duplicate mutations and dirty confirmation remain workflow-owned; compose Modal with pending Button for that workflow. Native heading/live-region intent does not establish DOM alertdialog equivalence or certify screen-reader speech.

The four added color roles copy existing canonical values only: overlayBackdrop is rgba(0, 0, 0, 0.3) in both modes; statusDanger is #b73434/#ff6b5f, statusWarning #a66b00/#f0b429 and statusSuccess #2f7d18/#6ad060 (light/dark). Info uses controlSelectedBackground. Tone roles remain independent of validation-border overrides. Every pre-existing default and all dependency pins remain unchanged; inherited palette findings and iPhone signing remain deferred.

`PlaceholderText` composes native Text with b11, italic, controlPlaceholder and left/default or center alignment. It exports alignment constants, their as-const array and derived type. Typography/color shorthand props are sealed, while customStyles and final style retain Text precedence and native color validation. Native Text refs, props, text scaling and label/test aliases remain available.

`ComboBox` is the bounded single-selection searchable counterpart. Its named summary trigger opens an opaque full-screen safe-area window with one stable query Input, a reachable Close and virtualized results. It uses shared TypeScript and the existing optional overlay leaf registration, preserving caller/theme context. Query focus is explicitly caller/user initiated; results start at the current collection’s first row. This mobile presentation has no inline anchored-editor claim. Keyboard avoidance and keyboardShouldPersistTaps=handled preserve separate query/result/Close targets; installed acceptance remains a separate tier.

Supply readonly already-filtered or async items/getKey/getTextValue, a trigger accessibilityLabel/aria-label, inputLabel and closeLabel. Numeric/string keys and null keep their identity. value/defaultValue/onChange, inputValue/defaultInputValue/onInputChange and isOpen/defaultOpen/onOpenChange are three independent axes. An enabled row requests a changed selected key, its label as a changed query, then closure, in that order; each owner can repeatedly veto independently. Typing alone selects no key. Missing selected items retain the key without synthetic callbacks. Default query is read once: explicit empty remains empty; only omission seeds from the initial selected label. Later owner selection changes do not overwrite query; uncontrolled query accepts row query requests independently. Close/Back preserves text with no blur normalization. Ownership-mode switches require a keyed remount.

Disabled blocks opening/editing/selection and requests controlled closure once per takeover; the owner may decline. Read-only permits inspection and Close/Back while blocking edits/selection. Disabled keys cannot activate. Root View ref and explicit inputRef target distinct native instances. The root resolves dimensions/color → customStyles → final style; customInputStyles owns query TextInput presentation, customButtonStyles owns the summary Pressable, customInputButtonGroupStyles owns closed summary/open query groups and customOptionsListStyles owns FlatList presentation. Authored slot overrides retain native style validation. Root callbacks receive open/disabled/read-only/invalid and post-custom defaultStyle. Existing geometry, sizes, error-before-warning-before-success borders, focus ring and platform target minima remain. Supplied icon/row content is decorative native content; renderItem must not contain interactive descendants. Text scaling remains enabled by default.

inputProps is a narrow native keyboard/correction/color/selection/event-observer allowlist, with native defaults unchanged. It cannot replace value, text change ownership, name, identity or ref. Multiple selection, committed custom free text, defaultItems/defaultFilter/collation, DOM collection children, form submission, selected-key aliases, placement, shouldFocusWrap, focus/input menu triggers, class/portal props and the second web onOpenChange cause argument are excluded by executable contracts. These inherited capabilities remain later catalogue work. No query mirror, uncontrolled native fallback, text-event suppression, dependency or palette change is introduced; RN-TEXT-01 stays open independently.
