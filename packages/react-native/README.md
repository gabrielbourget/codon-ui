# @codon-ui/react-native

Private native-owned Codon foundation for the Expo SDK 57 / React Native 0.86.3 / React 19.2.3 laboratory. The package exports native Text, PlaceholderText, Avatar, Tag, TagGroup/TagGroupItem, Menu/MenuItem/MenuSeparator, Link, Breadcrumbs, Toaster, ThumbnailImage, ThumbnailShowcase, Button, ToggleButton/ToggleButtonGroup/SelectionIndicator/SharedElementTransition, ToggleSwitcher, Switch, Checkbox, CheckboxGroup, Input, TextArea, Radio, RadioGroup, NumberInput, Stepper, Slider, TimePicker, DateTimePicker, DateTimeRangePicker, FormField, TypeaheadSearch, CompactTypeaheadSearch, Pagination, Select, ComboBox, TagComboBox, ListBoxItem, Modal, AlertDialog, ClickPopover, Tooltip, HoverPopover, LinearProgress, Meter, CircularProgress, Counter, Indicator, LineSegment, CircleLoader, LaggingLinesLoader, Carousel/CarouselCounter/CarouselDots/CarouselCloseButton/CarouselPrevButton/CarouselNextButton, Panel, SortAndFilterPanel, Card, NativeDialogFocusScope, NativeDialogTrigger, NativeTooltipTrigger, the theme/overlay providers, hook and public types. Further component families follow the compatibility roadmap; closer owner visual review accompanies application feature integration.
