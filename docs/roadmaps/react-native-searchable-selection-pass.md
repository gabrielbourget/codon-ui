## Why This Family

The canonical [native catalogue](react-native-library-first-pass.md#4-full-component-ledger) and Wavemap's [M2 searchable-selection checkpoint](../../../wavemap/planning/mobile-app/roadmap.md#m2-slice) require dependent leaves before composites. Recommend PlaceholderText, then a bounded single-selection ComboBox feasibility pass. Input, Button, Text, ListBoxItem and typed collection helpers already exist. PlaceholderText is the remaining direct component dependency in ComboBox's manifest graph. ComboBox in turn feeds TagComboBox and Table; Table still needs numerous other leaves and date/time contracts, so this does not claim that Table is ready. Search components use PlaceholderText/ListBoxItem directly and retain separate contracts. Do not introduce Tooltip/Popover/Menu incidentally.

The complete current trees match canonical web revision `ddc9f066f67af4742e05e04bd870726141c44129`: ComboBox has seven files with tree SHA-256 `5709539d863c25a1632a1b5a63f85b0a3314d6be1c4e622cfe4814089be7d960`; PlaceholderText has five with `39d6413273fe9811153e50c23f35f11b07808735293f2184bb3bcda87de77879`. The digest hashes sorted repository-relative path, NUL, per-file SHA-256 and newline records. Both focused web suites pass 17 cases. The private Select acceptance packet retains per-file identities, dependency edges and source-screening material. Tests largely cover wrapper styling/labels, so inherited editing/selection behavior needs dedicated native cases.

## Canonical Contracts And Candidate Fit

[ComboBox](../../packages/react/src/components/ComboBox/ComboBox.tsx), [calibration/types](../../packages/react/src/components/ComboBox/helpers.tsx), [labels](../../packages/react/src/components/ComboBox/labels.ts) and [styles](../../packages/react/src/components/ComboBox/ComboBoxStyles.module.css) compose React Aria Components 1.17.0, Input, Button, a Popover/ListBox and PlaceholderText. Root dimensions/color → customStyles → final style is distinct from input/button/group/list slots. Defaults include rounded geometry, medium text, focus/offset ring, error-before-warning-before-success validation and localized internal copy. Web rotation animation, CSS placement, DOM collection children and form behavior are separate from native input/selection semantics.

The installed inherited declarations and executable React Stately 3.46.0 state were inspected. Current `value`/`defaultValue`/`onChange` remain available; the wrapper omits the deprecated selectedKey/defaultSelectedKey/onSelectionChange aliases. `inputValue`/`defaultInputValue`/`onInputChange` are distinct from selection. TagComboBox demonstrates caller-owned input and `value={null}` with an add-item callback. Controlled `items` bypass React Stately's default filtering; the caller owns their contents. DefaultItems/defaultFilter, custom text values, multiple selection, menu triggers and blur normalization are additional inherited capabilities, not established by the styling suites.

## Proposed Native Contract

Implement PlaceholderText first as a narrow Text composition: `b11`, italic, existing `controlPlaceholder` color, left/default or center alignment, native Text props/ref and the established test/label aliases. Keep typography/color props sealed as in the canonical type; native text styles retain the existing documented precedence and color validation. Export the two alignment constants, an as-const array and derived type. Use no new theme role or palette value. DOM element/class/ref behavior stays excluded under the established native Text contract.

For ComboBox, propose an explicitly documented mobile presentation: a named summary/trigger opens a full-screen, safe-area list window with one stable editable query field above virtualized results and a reachable Close action. The editor stays in that window while open. The closed trigger displays the current query text, or its placeholder when empty; the selected key remains a separate owner-controlled value. Independent owner vetoes may therefore preserve different query and selection values. This differs from the web's inline editor plus anchored Popover and requires owner approval; do not silently claim inline/anchored parity. Use shared TypeScript and the existing caller-owned native-window/leaf registration pattern. Standalone use remains possible; nesting participates in the existing provider chain. No new sibling-stack policy, host placement or public provider contract is proposed.

## Proposed Four Passes And Stop Conditions

1. **Leaf and executable contract.** Add PlaceholderText with focused tests/types. Freeze single-key/query/open ownership examples and the native presentation/ref/style/label exceptions above. Audit native source files before sharing any private helper. Commit this coherent leaf/contract boundary.
2. **Bounded ComboBox implementation.** Compose current native leaves/window behavior, add public-outcome cases for three independent controlled axes, numeric/string/null, owner vetoes, collection updates/async result replacement, disabled/read-only/empty/custom content and teardown. Run affected tests, types/contracts, lint/format and package build. Commit source independently.
3. **Fresh consumer and priority installed gate.** Freeze a new archive/consumer with unchanged pins and matching maps. On both installed Release platforms, prove a freshly focused controlled query's unpaced typing, native/callback/committed owner agreement while focused, result replacement and a visible result's first activation with the keyboard active. Also prove keyboard-active Close/Back, parent draft/context/theme retention and reopening. Preserve the first failure and allow only a directly attributed localized correction plus its regression. RN-TEXT-01 remains owned until its own evidence supports closure; a passing single query does not rewrite that history. If a critical gate fails without attribution, stop propagation, preserve the exact binary/inspector and prepare a repair/runtime proposal.
4. **Maintained scene and receipt, conditional on the gate.** Add the accepted generic searchable-selection form composition, 200-result/empty/large-text/rotation/removal checks, current docs and final source/installed receipts. Rebuild only artifacts invalidated by actual changes. Restore/stop guests. Record physical/visual/ARM limits, remaining inherited capabilities and TagComboBox/Table/date dependencies. Commit the handoff separately.

Approval covers these four logical passes and normal commits, with no new dependency or palette/toolchain change. The mobile presentation and bounded API/exceptions above are authorized. The next stop is an unexplained installed critical-gate failure or a finding outside this scope; routine implementation and coherent commits proceed without another approval request. Registry/CLI, release/publication, sibling repo edits, physical signing and a general anchored-overlay framework remain outside the run.

## Pass 1 — Frozen Executable Contract And Source Audit

The handoff authorizes this exact four-pass run and a coherent commit after each completed pass. PlaceholderText composes native Text directly: b11 italic and controlPlaceholder, left/center alignment, native Text ref/events/labels and computed → customStyles → final style precedence. Typography/color shorthand props remain sealed; native styles retain Text validation and precedence.

The executable [positive/negative contract](../../packages/react-native/type-tests/searchable-selection.tsx) freezes ComboBox before broad implementation. The root ref targets its nonaccessible View; inputRef targets the separately named query TextInput. accessibilityLabel/aria-label names the summary trigger, inputLabel names the editor and closeLabel names Close. Root dimensions/color → customStyles → final style remain distinct from customInputStyles (query), customButtonStyles (summary Pressable), customInputButtonGroupStyles (closed summary group and open query group) and customOptionsListStyles (FlatList). Native inputProps is an explicit keyboard/color/selection/event-observer allowlist; value, identity, naming and change ownership cannot be overridden there. No auto-focus policy is added. Changing controlled/uncontrolled ownership of any axis during a mounted instance is unsupported; use a keyed remount.

The source audit finds reusable typed collection normalization in Select/collection.ts and the existing useOverlay leaf registration, with caller-local rendering under a native window. Share collection validation narrowly within the native package, preserving Select behavior and diagnostics. Keep the new editor/list presentation component-owned; do not extract a public or general search/overlay framework. Input remains the sole native text wrapper, without mirror state, event suppression, blur normalization or keyboard-default changes. Query focus remains stable across result replacement; result activation requests selection, label-as-query and close in that order. Same-value requests are suppressed independently per axis. An uncontrolled query accepts the row’s query request independently; later owner value changes alone do not overwrite it.

Focused leaf verification passes 15 cases across PlaceholderText/Text and strict executable public contracts. The normal commit hook supplies shared formatting/lint/types/contracts checks for this documentation/source boundary.
