## Observed Boundary

The installed iOS 26.5 x86_64 Release app cannot construct the parser's locale symbols: its number formatter lacks formatToParts. The diagnostic screen reports the missing method, while the symbolicated Hermes stack resolves to `@internationalized/number` 3.6.6, dist/private/NumberParser.mjs:214, the call to symbolFormatter.formatToParts(-10000.111). The original crash and the subsequent readable diagnostic retain separate binary/source identities. Source/Node/consumer checks passing does not close this native gate. Android's independent result belongs to the execution ledger.

The [FormatJS Hermes guide](https://formatjs.github.io/docs/guides/react-native-hermes/) describes partial native number-format support and explicit, ordered consumer polyfills. The [number-format documentation](https://formatjs.github.io/docs/polyfills/intl-numberformat/) covers its locale data and prerequisites. Recommend this explicit host setup rather than changing the approved decimal contract. Read-only screening of published number utility 3.6.5 also found formatToParts calls; selecting that older parser would not remove the demonstrated requirement. It was not installed.

## Proposed Ownership And Exact Dependencies

Let the consumer own global Intl preparation. Add no automatic polyfill side effect, new public initializer, peer, locale provider or FormatJS runtime dependency to `@codon-ui/react-native`. The showcase owns an app-local bootstrap loaded before App and the native package barrel; the independent archive consumer declares and initializes its own copy. Wavemap and sibling repos remain separate future integrations.

Propose these exact direct showcase dependencies, with the same pins in the private consumer example. The official npm metadata was screened on 2026-10-15; all exceed the repository’s seven-day minimum release age and declare MIT with no React/native peers. Their published prerequisite entry points are conditional; bootstrap will load them only when required. This approval includes their declared transitive graph, subject to inspecting and recording exact resolutions without unrelated lockfile drift.
