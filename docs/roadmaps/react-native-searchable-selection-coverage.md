Status: **Focused coverage audit; gaps remain open**. Gabriel clarified on 2026-10-16 that native verification should at least cover the canonical web components' contract surface so native capability/customizability can reach the intended ballpark. The canonical trees remain at reviewed revision ddc9f066f67af4742e05e04bd870726141c44129. This is not a 53-component retrospective parity certification. The full ledger still requires a contract audit at each family's kickoff and closeout.

## Capability And Runtime Disposition

The source slice owns a single typed key/null, independent controlled/default query and visibility, readonly caller-filtered/async items, missing-key retention, guarded rows, root/input refs, theme styles and distinct root/input/button/group/list slots. Native ownership/veto/async/ref/teardown tests add behavior coverage beyond the canonical wrapper suite's current styling assertions. That additional coverage does not cancel the missing customization assertions above.

The approved full-screen native presentation, explicit target names, safe-area handling, native keyboard behavior and context-preserving leaf registration are deliberate native equivalents. Inline anchored presentation, alternate menu triggers, default collections/filter/collation, committed custom free text, multiple selection, DOM collection/form/class/portal APIs and web focus wrapping retain explicit later dispositions under the [approved bounded contract](react-native-searchable-selection-pass.md). They are not silently certified as parity or erased from the catalogue. Review each capability against actual consumer needs before its implementation plan; platform-only exclusions need an honest native equivalent or documented reason.

Installed acceptance is currently blocked by the first query's N-only failure in the [receipt](react-native-searchable-selection-receipt.md). The [approved delivery diagnostic](react-native-query-delivery-diagnostic-pass.md) investigates that reliability boundary with unchanged production code. Neither its source tests nor a future passing diagnostic closes the original first-result-activation, keyboard-active Close/Back, nested context/draft/theme, large-text/rotation/removal or physical/ARM/signing gates. TagComboBox, Table and later dependent families remain pending.
