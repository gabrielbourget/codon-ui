This does not supply upstream's missing declarative open/defaultOpen state input, and the trial does not silently remove Codon's open-state contract.

Source tests verify callback/count/closure behavior with system dismissal blocked, while the earlier isolated throw-order probe remains applicable. The trial distinguishes explicit action closure from system closure locally; this adapter responsibility is not attributed to the upstream API. Portal/native-window composition preserves parent-local state while covered, and complete closure resets it. Root-portalled content receives host-context; the current native-window arrangement retains caller-local context. This confirmed difference remains an adoption gate, even though the diagnostic intentionally asserts the observed value and passes.
