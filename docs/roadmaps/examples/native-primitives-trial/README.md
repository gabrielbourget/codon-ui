# Isolated RN Primitives Trial Source

These are documentation-owned, non-shipping trial sources for [the approved proposal](../../react-native-primitives-adoption-proposal.md). They are not a new workspace, registry entry or replacement implementation in packages/react-native. The [source/consumer receipt](../../react-native-primitives-trial-receipt.md) records exact inputs and limits. Native components remain shared TypeScript/TSX; generated platform build scaffolding and private XCTest code are lab infrastructure.

The source runs in a fresh isolated copy of the existing frozen native consumer, using the immutable Codon archive from source 13f267c21e125f7d0ca03132bdeed7e0667a7ea8 with SHA-256 3895f79a424093d7ced21e726d9f7e6753f15251b2951ac1835d05c548e7d89b. Direct trial additions are @rn-primitives/dialog 1.5.2, @rn-primitives/alert-dialog 1.5.2, @rn-primitives/select 1.5.2 and @rn-primitives/portal 1.5.3. Preserve the existing Expo 57.0.26, React 19.2.3, RN 0.86.3, safe-area 5.7.0 and Intl bootstrap. The actual frozen package/lock/config/bootstrap inputs live in the evidence packet, avoiding a second installable workspace or a large duplicate lockfile in documentation.

App.tsx compares provider-scoped root portals with primitive content inside the current Codon native-window host. It retains Codon Text/Button/Input/ListBoxItem, theme roles, six status marks and controlled selected values. trial-styles.ts supplies typed pure calibration helpers. DefaultMark.tsx preserves the current native mark rendering, with imports adjusted to the archive's public types/theme. The Select adapter encodes numeric/string keys and uses a private empty sentinel because upstream undefined selects uncontrolled ownership; it does not add declarative open-state support.

trial.test.tsx has seven focused cases. Nested native windows need captured show/dismiss completion callbacks and direct native activation delivery in the mocked renderer, whose React ancestry is not a physical window hierarchy. Those cases establish source behavior, not touch geometry, screen-reader output or installed readiness. The portal context case deliberately asserts the observed host value to record the contract mismatch; a passing diagnostic is not acceptance of that context change. The independent consumer's two earlier composition cases remain separate.

To reproduce, copy these files into a fresh consumer prepared from the recorded accepted inputs, retain index.ts/number-format.ts and the archived baseline type/composition cases, then use its frozen install and existing compiler/Jest/Metro commands. The scoped Jest transform includes @rn-primitives and zustand, with native safe-area layout mocked only in tests. Do not install the trial dependencies into the Codon root or native package as an incidental reproduction step. The dependency/identity/maps and native build commands are recorded under the private reproduction directory.
